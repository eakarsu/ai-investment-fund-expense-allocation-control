# Investment Fund Expense Allocation Control

Prevent prohibited or inequitable allocation of operating, deal, compliance, and shared expenses across funds and the manager.

**Primary buyer:** Fund managers, boards, and investors. **Evidence:** fund documents, allocation policies, invoices, time records, vendor services, fund assets, investor classes, co-investments, broken deals, reimbursements, and NAV entries.

Full local application built with React, Vite, Express, PostgreSQL, and OpenRouter. Includes 15 domain-specific capabilities, 105 custom AI workbench fields, three scenario-fill controls per feature, operational registers, workflow transitions, analytics, professional AI decision briefs, audit history, and at least 15 PostgreSQL records per capability.

## Domain capabilities

- Allocation policy library
- Fund entity registry
- Vendor invoice ingestion
- Expense category classification
- Manager versus fund test
- Shared service allocation
- Time-record allocation
- Broken-deal allocation
- Co-investment treatment
- Cross-fund allocation
- Class-level allocation
- Policy exception workflow
- Reimbursement calculation
- NAV correction reconciliation
- Fund expense analytics

Run `./start.sh`, then open <http://127.0.0.1:4674>. API: `5674`.
